# Use embodied controls and tool-first interactions

The player will use WASD or arrow-key movement, a gentle follow camera with optional mouse orbit, an interact button, and a compact tool wheel instead of click-to-move or menu-first controls. When the player interacts near multiple targets, a valid equipped-tool action wins before the nearest generic interactable; this keeps fishing, bug catching, digging, chopping, and mining grounded in place rather than flattening them into generic clicks.

## Considered Options

- Embodied third-person controls with tool-first interaction priority.
- Click-to-move with contextual actions.
- Context menus for crowded interaction cases.

## Consequences

Creature catches should use lightweight timing, range, or angle mini-actions. The Pocket should have a real but generous slot limit so selling, donating, and returning home remain part of the island life loop. Villagers should provide reactive atmosphere and tiny favors, not hard progression gates.
