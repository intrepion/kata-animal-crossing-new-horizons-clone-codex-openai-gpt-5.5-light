# Ship one complete island day

The first playable target is one complete island day rather than a broad open-ended sandbox. The slice should include gathering, crafting, tool use, fishing, bug catching, selling, museum donation, NookPhone tasks, villager interaction, and a starter loan milestone so the result feels like island life instead of a menu of disconnected features.

## Considered Options

- One complete island day.
- Larger open-ended sandbox with shallow activities.
- Guided quest-only demo.

## Consequences

Scope decisions should protect a dense, finished day over extra area size or feature count. The island can be small, but each visible landmark should support the island life loop.
