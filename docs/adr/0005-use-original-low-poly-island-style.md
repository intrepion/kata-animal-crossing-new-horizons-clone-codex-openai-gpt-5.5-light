# Use original low-poly island style

The game will use an original low-poly toy-like island style with rounded forms, readable silhouettes, bright materials, and soft shadows rather than trying to copy Nintendo characters, names, or exact art. The goal is to preserve the recognizable cozy island-life fantasy while avoiding brittle imitation and keeping the browser scope achievable.

## Considered Options

- Original low-poly toy-like island style.
- Closer Animal Crossing: New Horizons character and naming imitation.
- Generic stylized diorama with weaker reference to the source fantasy.

## Consequences

Characters, shopkeepers, museum staff, task names, and props should be original even when they fill familiar roles. Visual work should prioritize clarity, charm, and interactable affordances over exact fidelity.
