# Ground verbs in readable landmarks and HUD

The island will be built from a small set of mandatory Landmarks: plaza, player tent or home, beach, river or pond, grove, rock garden, museum tent, shop stall, crafting stump or table, and one villager yard. Interaction readability comes from a subtle World Prompt over the current target plus a compact HUD showing Equipped Tool, Pocket space, Bells, and Current Task.

## Considered Options

- Small dense landmark set with visible world prompts and compact HUD.
- Larger island with more negative space.
- Menu-heavy state with fewer in-world prompts.

## Consequences

Each core verb should have a physical home. State that changes moment to moment should stay visible enough for play, because hiding Pocket pressure, Bells, or the next task in menus would make the island feel more like a dashboard than a place.
