# Use a scripted island day with soft friction

The Island Day will follow a scripted morning-to-evening arc instead of real local time or a fast clock. Crafting will use a small Recipe Book unlocked by NookPhone Tasks, New Catches will make the sell-or-donate choice explicit, catches may fail, and resource nodes may have short cooldowns, but tools will not break in this slice.

## Considered Options

- Scripted one-day arc with visible morning-to-evening progression.
- Real local time.
- Accelerated in-game time.

## Consequences

The day can finish in one sitting while still feeling like a day. Soft friction should make actions legible and satisfying, not add maintenance chores that crowd out the Island Life Loop.
